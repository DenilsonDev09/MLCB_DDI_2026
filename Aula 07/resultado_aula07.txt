EXERCÍCIO 01: Pré-processamento — Stopwords e Lematização 
--------------------------------------------------------------------------------
Cenário: Um e-commerce precisa limpar uma lista de tokens para remover ruídos.


tokens = ["os", "produtos", "comprados", "não", "chegaram"]
stopwords = ["os", "não"]

# TODO: Crie uma lista vazia chamada tokens_limpos
tokens_limpos = []

# TODO: Percorra cada palavra da lista 'tokens' usando um laço for
# - Se a palavra estiver em 'stopwords', ignore-a.
# - Se a palavra for "comprados", adicione "comprar" na lista limpa.
# - Se a palavra for "chegaram", adicione "chegar" na lista limpa.
# - Para as demais palavras, adicione-as sem alteração.


for palavras in tokens:
  if (palavras in stopwords):
    pass
  elif (palavras == "comprados"):
    tokens_limpos.append("comprar")
  elif (palavras == "chegaram"):
    tokens_limpos.append("chegar")
  else:
    tokens_limpos.append(palavras)

# TODO: Imprima a lista tokens_limpos
print(tokens_limpos)

['produtos', 'comprar', 'chegar']

#Responda: Qual a diferença entre Stemming e Lematização? Por que a Lematização garante que a palavra exista no dicionário e o Stemming não?
R: O Stemming ele reduz as palavras e pode gerar algumas que não existe, a Lematização busca o lema das palavras em formato de dicionario. A Lematização ela transforma a palavra no seu lema.

R: As palavras que tende a exibir poucas vezes tem maior peso, as que aparecem varias vezes tende ter o peso menor.

EXERCÍCIO 07: Limpeza de Texto — Tokenização, Pontuação e Stopwords
--------------------------------------------------------------------------------

#Cenário: Higienização de mensagens em um sistema de chamados.
bruta = ["O", "sistema", "está", "muito", "lento", "hoje", "!"]
stopwords = ["O", "está"]

# TODO: Crie uma lista vazia chamada tokens_limpos
tokens_limpos = []

# TODO: Percorra a lista 'bruta' com um for e adicione à 'tokens_limpos' 
# apenas as palavras que NÃO estejam em 'stopwords' e que sejam diferentes de "!"
for palavra in bruta:
  if not palavra in stopwords and palavra != "!":
    tokens_limpos.append(palavra)

# TODO: Imprima a lista tokens_limpos
print(tokens_limpos)
['sistema', 'muito', 'lento', 'hoje']

#Responda: O que são Stopwords e por que sua remoção é importante no pré-processamento?
R: Stopwords são palavras muito comuns e pouco relevantes para certas análises, como “o”, “a” e “de”. Sua remoção ajuda a reduzir ruídos e focar nas palavras mais importantes do texto.
